# 03 UI 规范（DOM / 状态类 / 界面条款 / 主题）

> 本文件是界面部分的**唯一**规范。旧文档里散落的界面描述一律作废，以本文为准。
> 数据字段见 `02-契约.md`；本文只管界面与可验证的交互要求。
> 可选插件的入口、平台名和认证方式来自插件声明，不由 model-team 再写一份名单；全项目低耦合边界见 `06`。
> 反代前端继续改造暂缓；已存在的账号区不能当作完整 Qoder 接入验收通过。

## 一、界面组成

```
悬浮球（收起态）
  └ 点击 → 悬浮面板（五行信息 + 两个按钮）
       └ [进入群聊界面] → 主窗口
            ├ 顶栏：团队 | 当前视图名（不设收起键、不设关闭键）
            ├ 内容区 #viewRoot（按 tab 切换）
            └ 底边栏：消息 / 通讯录 / 我   ← 唯一的视图入口
```

**入口唯一（INV-13）**：三个视图只能从底边栏进入。顶栏、群列表头部都**不得**再放入口按钮。

**退出路径唯一**：主窗口不设「收起」也不设「关闭」按钮（2026-11-09 定）。回球靠点悬浮球或 ESC；球的显隐由 INV-14 决定，用户不手动关。面板标题条右侧的 `—` 是**面板层**的收起（面板→球），与主窗口无关，保留。

### 技术形态（已定稿，取代早期框架方案）

界面用**纯静态 HTML + CSS + JS**，不引入框架、不跑前端构建工具链：

- 设计稿 `ui/index.html` 可直接在浏览器打开预览（受限挂载环境也能看）
- 插件产物 `lib/client.js` 由 `build.cjs` 拼接分片 + 内联骨架与样式生成
- 讨论期曾评估 **Vue 3 + `fake-qq-ui`**（聊天气泡组件库）作为可选方案；阶段 1 裁决改为纯静态，理由是**受限挂载环境（CIFS/SMB）必须能直接预览，不依赖依赖安装与构建链**。

> 早期框架方案作废；若将来引入框架，需先在 `13` 登记理由与代价（会破坏「受限挂载可直接预览」这一前提）。

## 三、状态类与属性（JS 只动这些）

| 类 / 属性 | 语义 | 主题必须做什么 |
|---|---|---|
| `.hidden` | 隐藏 | 用 `visibility/opacity/pointer-events` 组合，**禁止 `display:none`**（否则开合动画失效） |
| `.is-dragging` | 拖动中 | `transition: none; will-change: transform` |
| `[aria-selected="true"]` | 当前 tab | 高亮 |
| `.avatar-img` / `.avatar-fallback` | 头像图 / 文本占位 | 图片失败时 JS 换成 fallback |
| `[data-collapsed]` | 面板折叠态 | 对应视觉 |

**禁止**：JS 直接写 `element.style.*` 的尺寸/颜色/圆角——一律由主题 CSS 决定。
唯一允许的内联样式：拖动位移 `transform` 与落位 `left/top`。

## 六、交互实现要点（踩过坑的）

| 要点 | 正确做法 | 历史事故 |
|---|---|---|
| 悬浮球开合 | `pointerdown` 只记录 `panelWasOpen`；超 4px 才算拖动并收起；`pointerup` 未移动时按 `panelWasOpen` 决定开/关 | F-01：`pointerdown` 里直接收面板导致"只能开不能关" |
| 渲染后聚焦 | 渲染前记 `document.activeElement`，只有原本就在输入框才恢复；打开主窗口后主动 `blur()` | F-02：每次渲染无条件 focus 搜索框，移动端弹软键盘 |
| 重复挂载 | 检测 `.dmt-host` + `#floatDock` 同时存在就复用，只有孤儿节点才清理重建 | F-03：二次挂载后新 DOM 无监听，切换 session 面板空白 |
| 系统消息 | 只从后端 events 读，前端**不许**本地插入 | F-04：前端插 + 后端存双源，刷新后文案不一致 |
| 多源合并排序 | 先定排序键（`at`，缺失用 `time`）+ 同键规则（rows 在前），再写渲染 | F-05：两段拼接导致每次进入顺序不同 |
| 固定尺寸容器放长文本 | 必须量 `scrollWidth > clientWidth`，用最长可能值测 | F-06：球内文字溢出球体 |

## 六点五、悬浮件状态与位置

悬浮球与悬浮面板的「显隐 / 位置 / 展开方向」只有一处真相源：`ui/js/dock-state.js`（状态工厂）。

| 项 | 口径 |
|---|---|
| 显隐 | 工厂里的 `visible` 是唯一来源；`dock.js` 只把 INV-14 判定结果写进工厂（`setDockVisible(decision === 'ours')`），**不留显示副本**；DOM 的 `display` 由注册的 applier 落地 |
| 位置 | 只持久化**收起态锚点** `{left, top}`（球的左上角）；面板位置由「锚点 + 面板尺寸 + 展开方向」算出，**不落盘** |
| 夹取 | `clampDockPosition(left, top, size)`：`min=0`、`max=max(0, 视口-尺寸)` ⇒ **整块留在视口内**；球用球尺寸、面板用面板尺寸，各按当前形态夹 |
| 展开方向 | `computeOpenDir()`：锚点中心相对视口中心决定象限（`openLeft = cx ≥ vw/2`、`openUp = cy ≥ vh/2`），写到 `#floatDock[data-open-dir]`；球靠右→文本在左、靠左→文本在右（永远朝视口内侧）。拖动松手与 resize 后重算 |
| 动效 | 只过渡尺寸/透明度/位移（`width 220ms cubic-bezier(.16,1,.3,1)`、`opacity 180ms`、`transform 220ms`）；`left/top` **不参与过渡**，否则拖拽会发飘 |
| 旧键迁移 | 历史键 `dsh-model-team:anchor` 在工厂加载时迁移进 `dsh-model-team:dock-state-v2` 并删除旧键，避免两份真相并存 |


## 七、主题（TSX）

**一句话**：主题只声明「控件、大小、样式、内部动作」；数据与对外动作由宿主提供。主题不联网、不碰存储、不直接调 `/_team`。

### 7.1 形态与构建

| 项 | 规定 |
|---|---|
| 一个主题 | 一个 `.tsx` 文件（如 `ui/themes/classic.tsx`、`ui/themes/tim.tsx`），可并存多个，运行期切换 |
| 构建 | TSX 在**构建期**编译成 CJS bundle，内联进 `lib/client.js` 的 `ModuleLoader` 工厂；运行期不加载裸 ESM |
| 依赖 | `react` / `react/jsx-runtime` / `react-dom` 由 DSH 宿主提供（产物只留 `require` 字面量，不打包 react）；构建期工具（如编译器）放 `devDependencies`，不算破零依赖 |
| 样式 | 主题自带样式（内联或随 bundle），不得全局污染宿主：所有选择器限定在主题根节点下 |

### 7.2 主题声明形状

主题默认导出一个声明对象，宿主只认这些字段：

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 主题标识（与文件名一致），用于配置与切换 |
| `name` | 是 | 展示名 |
| `size` | 否 | 主窗口尺寸覆盖（`width` / `height`，CSS 长度字符串）；缺省用 `04` 条款 10 的默认值 |
| `styles` | 否 | 该主题的样式表（字符串或列表） |
| `render` | 是 | 渲染函数：接收宿主注入的 `bridge`，返回界面 |
| `actions` | 否 | 主题内部动作（如「记住上次 tab」这类纯视觉状态操作），不参与宿主数据 |

**主题本地状态归主题**（当前 tab、@ 浮层开合、请求卡片展开态、输入框草稿）；**跨页面或需持久化的归宿主**（当前群、当前目标、悬浮件锚点与开合）。

### 7.3 主题能做什么 / 不能做什么

| 能做 | 不能做 |
|---|---|
| 决定控件长什么样、用什么控件、尺寸与样式 | 自己 `fetch` / 读 `localStorage` / 直接调 `/_team` |
| 组合宿主给的组件与数据 | 改宿主 store 的内部字段、注册新端点 |
| 主题内部纯视觉状态 | 伪造业务数据（缺数据显示空态，不许编造） |
| 覆盖窗口尺寸、颜色、圆角、字号 | 全局改写宿主页面样式（含 `body`、宿主浮层） |

### 7.4 与宿主的边界

- **宿主提供**：数据（见 §八）、动作（见 §八）、悬浮件状态、会话与目标解析。
- **主题提供**：视图结构 + 样式 + 本地视觉状态。
- **悬浮球/悬浮面板**：由主题渲染（视觉），**状态与几何**（显隐、锚点、展开方向、命中判定）由宿主维护；主题不得自己持久化这些状态。
- **禁用项（硬）**：主题内出现 `fetch(`、`localStorage`、`/_team`、`window.__` 直接访问即视为越界，构建门禁会红。

### 7.5 切换与兼容

| 场景 | 规定 |
|---|---|
| 缺省主题 | 未配置时用内置默认主题；配置指向不存在的主题 → 构建失败并带出路径，不静默回落 |
| 切换主题 | 运行期切换不得重建宿主页面；切换后宿主关键状态（当前会话、目标、群列表）必须保持不变 |
| 旧通道 | 旧的「主题 = 一份 HTML 骨架」通道仅作过渡：TSX 主题全量接管后再删；过渡期两套可切换，但**不得同时渲染** |

## 十一、验收判据

| # | 判据 | 验证方式 |
