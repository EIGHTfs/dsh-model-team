# 19 Qoder 登录流程调研（逐行对照，含行号）

> 目的：把「登录到底该怎么做」按**源码行号**钉死，不再凭印象。
> 三个来源：`dsh-providers-hub`（JS，部署副本）、`qoder2api-hub`（Python，克隆在仓库外 `_refs/`）、`proxy-hub`（Node，同）。
> 结论先行：**CN 设备授权必须带 `redirect_uri`，且 `machine_id` 要用本机真实 id** —— 我们两处都没做，这就是「流程不一样」的实质。

## 一、三家各自怎么做（行号可直接跳）

### 1. dsh-providers-hub（JS，`lib/qoder.js` + `lib/qoder-oauth.js`）

| 环节 | 行号 | 内容 |
|---|---|---|

| 授权 URL | `qoder.js:76-85` | `{authBase}/device/selectAccounts?challenge&challenge_method=S256&nonce&machine_id&client_id`（**只有 5 个参数，无 `redirect_uri`**） |
| client_id | `qoder.js:70-74` + `qoder-product.js:335` | CN 用 `732aef47-9cf2-46a2-95fe-4cebb5d0d1fa`；注释强调「必须用 prod 值，否则回调阶段被拒」 |
| 轮询 URL | `qoder.js:93-100` | `{openApiBase}/api/v1/deviceToken/poll?nonce&verifier&challenge_method=S256`；注释指明**必须挂 openApiBase** |

## 二、我们的实现 vs 参考（差异清单）

| 项 | 我们（`src/reverse/platforms/qoder/oauth.js`） | CN 参考（Python:4458-4462） | 判断 |
|---|---|---|---|
| `redirect_uri` | **未发送**（`buildAuthUrl` 只有 5 个参数，`oauth.js:60-68`） | **必发** `qoder-work-cn://` | ❌ 缺陷 |
| `machine_id` | 随机 uuid（`createDeviceSession`，`oauth.js:54`） | 本机真实 id（`:4462`） | ❌ 缺陷 |
| `client_id` | `732aef47-…`（取自 providers-hub `qoder-product.js:335`） | `1c5e33e1-…`（`:256`） | ⚠️ 两家不同，需真机判定 |
| nonce | `randomUUID()` 带横线 | CN 带横线 | ✅ |
| 轮询参数 | nonce/verifier/S256 | 同 | ✅ |
| pending 状态 | 仅 404（`oauth.js:147`） | 404 **或 202** | ⚠️ 少一个 |
| token 字段 | `token`/`device_token`/`access_token` | 同 | ✅ |
| 用户信息 | `/api/v1/userinfo` | 同 | ✅ |
| 续期端点 | 未实现（M4） | `deviceToken/refresh`；且 **按 token 前缀分流** | 待 M4 |

## 三、由此得出的修法（按优先级）

1. **CN 授权 URL 补 `redirect_uri=qoder-work-cn://`**（配置化，别写死在函数里；Intl 不带）
2. **`machine_id` 用本机真实 id**：找不到就生成一次并持久化（绝不每次随机）；落盘位置与凭据同目录
3. **轮询把 202 也算 pending**
4. **`client_id` 做成可配置**（默认 CN 用 Python 参考值，保留 providers-hub 值作为备选常量），并**在登录日志里打印用的是哪个** —— 真机一次就能判定哪个对
5. M4 时按 **token 前缀**分流续期端点

## 四、仍未解决（需要真机）

- 到底是 `1c5e33e1-…` 还是 `732aef47-…`：两家都声称可用，只有真机能定。做法是让配置可切换 + 日志可观测，一次登录就能看出。
- `machine_id` 在 CN 侧是否必须与某处（IDE/CLI 安装）一致：Python 用「本机 id」，providers-hub 用随机；两者都声称能登录，真机验一次即可判定是否需要稳定化。
