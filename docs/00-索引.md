## 三、三条铁律（违反即不算完成）

1. **契约唯一**：接口、字段、错误码只以 `02-契约.md` 为准；界面与主题以 `03-UI与主题契约.md` 为准。冲突即改文档。
2. **一手证据**：验收贴自己跑出来的输出；「应该没问题」「本地 mock 通过」不算证据。
3. **不许猜**：契约没写的先冻结，不许按惯例先做一版。

## 四、门禁命令（交付前必跑）

```bash
node build.cjs                       # 构建客户端产物
node --test test/*.test.js           # 全部用例
node scripts/check-contract.mjs      # 契约 ↔ 路由 ↔ DOM 钩子
node scripts/check-doc-refs.mjs      # 文档编号引用不指向不存在的文件
node scripts/gate-all.mjs            # 一次跑完全部门禁
```

## 六、文档怎么写

- 只写**当前有效**的结论与依据；不写讨论过程、不写「第 N 轮」「用户说」
- 一个事实只出现在一份文档里；其它地方只引用编号
- 状态性描述必须带核对日期；数字必须能回答「什么时候用什么命令核的」
