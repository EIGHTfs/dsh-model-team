# 03 UI 规范（DOM / 状态类 / 界面条款 / 主题）

> 本文件是界面部分的**唯一**规范。旧文档里散落的界面描述一律作废，以本文为准。
> 数据字段见 `02-契约.md`；本文只管"长什么样、有哪些钩子、怎么被校验"。

## 一、界面组成

```
悬浮球（收起态）
  └ 点击 → 悬浮面板（五行信息 + 两个按钮）
       └ [进入群聊界面] → 主窗口
            ├ 顶栏：团队 | 当前视图名 | ×收起
            ├ 内容区 #viewRoot（按 tab 切换）
            └ 底边栏：消息 / 通讯录 / 我   ← 唯一的视图入口
```

**入口唯一（INV-13）**：三个视图只能从底边栏进入。顶栏、群列表头部都**不得**再放入口按钮。

### 技术形态（已定稿，取代早期框架方案）

界面用**纯静态 HTML + CSS + JS**，不引入框架、不跑前端构建工具链：

- 设计稿 `ui/index.html` 可直接在浏览器打开预览（受限挂载环境也能看）
- 插件产物 `lib/client.js` 由 `build.cjs` 拼接分片 + 内联骨架与样式生成
- 讨论期曾评估 **Vue 3 + `fake-qq-ui`**（聊天气泡组件库）作为可选方案；阶段 1 裁决改为纯静态，理由是**受限挂载环境（CIFS/SMB）必须能直接预览，不依赖依赖安装与构建链**。

> 早期框架方案作废；若将来引入框架，需先在 `06` 登记理由与代价（会破坏「受限挂载可直接预览」这一前提）。

## 三、状态类与属性（JS 只动这些）

| 类 / 属性 | 语义 | 主题必须做什么 |
|---|---|---|
| `.hidden` | 隐藏 | 用 `visibility/opacity/pointer-events` 组合，**禁止 `display:none`**（否则开合动画失效） |
| `.is-dragging` | 拖动中 | `transition: none; will-change: transform` |
| `[aria-selected="true"]` | 当前 tab | 高亮 |
| `.avatar-img` / `.avatar-fallback` | 头像图 / 文本占位 | 图片失败时 JS 换成 fallback |
| `[data-collapsed]` | 面板折叠态 | 对应视觉 |

**禁止**：JS 直接写 `element.style.*` 的尺寸/颜色/圆角——一律由主题 CSS 决定。
唯一允许的内联样式：拖动位移 `transform` 与落位 `left/top`。

## 四、CSS token（主题可覆盖）

```css
:root {
  --team-window-width: min(760px, 92vw);
  --team-window-height: min(540px, 86vh);
  --team-tabbar-height: 54px;
  --team-blue-deep: #1f6feb;    /* 主色 */
  --team-text-1 / --team-text-2 / --team-text-3;
  --team-line;                  /* 分隔线 */
  --team-bg;                    /* 面板底色 */
  --team-shadow / --team-shadow-lg;
}
```

主题只声明需要的，缺省值由内置样式兜底。

## 五、界面条款（逐条可验收）

### 5.1 悬浮球 / 面板

| # | 条款 |
|---|---|
| 1 | 球显示当前目标：单模型显示模型名（过长截断，如 `(glm-5.3-fl…)`）；分组显示 `@分组名`；未设置显示 `—` |
| 2 | 标题栏：左 `👤 我的模型团队`（点击进数据库页）、中 `模型 <目标>`、右 `— x` |
| 3 | 面板五行顺序固定：`当前群聊` → `session：<标题>（<id 前8位>）` → `当前目标` → `📊 本 session 速率` → `📈 全局请求量（含 总计 X tok）` |
| 4 | 面板必须最顶层，不被宿主界面遮挡 |
| 5 | 「session」行用于验收切换 session 是否秒生效（无标题只显示 id；草稿 session 显示 `—`） |

### 5.2 主窗口

| # | 条款 |
|---|---|
| 6 | 底边栏三 tab，顺序固定：消息（`list`）/ 通讯录（`contacts`）/ 我（`profile`） |
| 7 | 图标一律**内联 SVG**，不引外部图片、不用 emoji 占位；选中态用主题色 + 实心/描边区分 |
| 8 | 顶栏只保留：`团队` 标识 + 当前视图名 + `× 收起`。**不得**再放通讯录/数据库按钮（INV-13） |
| 9 | 底边栏高度固定不滚动；内容区在其上方滚动 |
| 10 | 默认尺寸 `min(760px, 92vw) × min(540px, 86vh)`，宽高各由 CSS 变量控制 |

### 5.3 群列表

**隐喻来源**：群列表仿的是聊天软件的**消息列表**——一条「会话」= 一个平台账号（群）；「最新消息」= 该账号的账号信息（限速 / 限额 / 余额 / 并发等）。各平台字段不同，所以摘要由后端按 **env 模板**渲染成**单行成品字符串**（`02` §3.1 的 `summary`），前端只负责显示、不做拼装。

| # | 条款 |
|---|---|
| 11 | 顶部：`🔍 搜索群聊 (账号)` + `+ 加群`。**不设「我」入口**（INV-13，从底边栏进） |
| 12 | 每项：`[W] 群名` + 右侧时间（`10:30` / `昨天`，由 `lastUpdated` 本地化）+ 下一行摘要 |
| 13 | 头像用字符串占位（`[W]`/`[C]`/`[T]`），不引外部图片 |

### 5.4 加群

| # | 条款 |
|---|---|
| 14 | 标题 `新建群聊（添加账号）`；两段式：选平台 → 备注名称 + 鉴权凭证（按 `authSchema` 动态渲染） |
| 15 | 提交按钮文案 `校验并添加群` |
| 16 | 平台下拉两类选项：`preset:<平台id>` 与 `driver:<驱动id>`；提交时用 `resolvePlatformSelection()` 解析出 `{platform, driver}` |
| 17 | **提交后必须以后端返回的群为准**更新列表；失败必须提示且**不插入**本地对象（历史事故 G-12：失败被吞 + 幽灵群） |

### 5.5 群聊

| # | 条款 |
|---|---|
| 18 | 顶部 `< 返回` + 群名 + `[群友: N]`（N **进群时实时取** `GET /groups/:id/models`，不自算） |
| 19 | 请求卡片头显示实际响应的平台与模型；列序 `状态 \| 耗时 \| tokens \| credit \| 命中率`；`title` 悬浮完整日志；点击展开气泡 |
| 20 | 单模型切换系统消息：`你 @ 了 <模型> 并切换了当前 session 模型` |
| 21 | 分组切换系统消息：`已切换路由至：<分组名>（策略：轮询/故障转移）` |
| 22 | 我发出的消息为**右侧气泡**（`@模型名` / `@分组名`） |
| 23 | 消息流按 `at` 升序；新消息自动滚到底 |
| 24 | **回车发送**（`Shift+Enter` 换行）；点击头像即插入 `@名字` 并聚焦输入框 |
| 25 | 切换目标成功后**立即刷新悬浮窗**（球文本/模型标签/当前目标），不得要求刷新整页 |

### 5.6 @ 选择器

| # | 条款 |
|---|---|
| 26 | 两块（本群群友 / 我的分组带成员数）+ 分隔线；占位文案 `@ 选择群友或分组…` |

### 5.7 群聊跟随 session 目标

| # | 条款 |
|---|---|
| 27 | 切换 session 后，群聊默认显示**该 session 目标所属的群**：<br>· 目标是单模型 → 切到 `target.platformId` 的群<br>· 目标是分组或未设置 → **保留当前群聊**（分组跨平台无唯一归属）<br>· 目标群已不存在 → 回落第一个群 |

## 六、交互实现要点（踩过坑的）

| 要点 | 正确做法 | 历史事故 |
|---|---|---|
| 悬浮球开合 | `pointerdown` 只记录 `panelWasOpen`；超 4px 才算拖动并收起；`pointerup` 未移动时按 `panelWasOpen` 决定开/关 | F-01：`pointerdown` 里直接收面板导致"只能开不能关" |
| 渲染后聚焦 | 渲染前记 `document.activeElement`，只有原本就在输入框才恢复；打开主窗口后主动 `blur()` | F-02：每次渲染无条件 focus 搜索框，移动端弹软键盘 |
| 重复挂载 | 检测 `.dmt-host` + `#floatDock` 同时存在就复用，只有孤儿节点才清理重建 | F-03：二次挂载后新 DOM 无监听，切换 session 面板空白 |
| 系统消息 | 只从后端 events 读，前端**不许**本地插入 | F-04：前端插 + 后端存双源，刷新后文案不一致 |
| 多源合并排序 | 先定排序键（`at`，缺失用 `time`）+ 同键规则（rows 在前），再写渲染 | F-05：两段拼接导致每次进入顺序不同 |
| 固定尺寸容器放长文本 | 必须量 `scrollWidth > clientWidth`，用最长可能值测 | F-06：球内文字溢出球体 |

## 七、主题可替换（换主题 = 换一个 html）

**目标**：写一个新 html 满足本文 §二~§四 → 改配置指向它 → 代码零改动。

```jsonc
{ "theme": { "html": "ui/index.html", "styles": ["ui/app.css"] } }
```

| 环节 | 规定 |
|---|---|
| 骨架来源 | 构建期读主题文件（`config.theme.html`，缺省 `ui/index.html`）——**当前未实现，见 06 的 G-01** |
| 样式来源 | 主题自带 `<style>` 内联或 `<link rel="stylesheet">`，构建期一并内联 |
| 数据 | 主题**不得**自带业务数据，可变值全由 JS 填 |
| 交互 | 主题**不得**内联 `<script>` |

### 两道校验

| 时机 | 校验 | 失败行为 |
|---|---|---|
| 构建期（`build.cjs`） | `THEME_REQUIRED` 全部存在（`#floatDock`/`#floatPanel`/`.team-app`/`.team-tabbar`/`#viewRoot`）；骨架不含 `design-only` 区块 | **构建失败**，列出缺哪个 |
| 运行期（`app.js` 启动一次） | `assertThemeContract()` 检查 §二 必需 id | 控制台 `console.error` + 记 `storeErrors`，**不阻断**（界面降级可用） |
