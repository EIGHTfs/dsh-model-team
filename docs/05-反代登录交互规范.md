# 05 反代登录交互规范（实现依据，不许自由发挥）

> 依据：`dsh-providers-hub` 客户端登录实现（`lib/client/jet-hub.js:10145-10215`）的实测行为，取其交互节奏，不取其架构。
> 适用范围：加群页账号登录与刷新；**前端继续改造暂缓**，本文是验收要求，不是完成声明。
> 登录结果必须属于本次操作；不以弹窗打开、授权页成功提示或打桩轮询作为完整登录证据。平台参数与源码证据见 `09`，未定因故障见 `08`。

## 一、一次点击的完整时序（必须按此顺序）

```
用户点「登录 Qoder」
 ① 立刻：按钮禁用 + 文案变「正在打开授权页…」（同一帧内，不许等网络）
 ② 立刻：POST /_team/reverse/login/start
  ③ 主路径必须在第一次点击后打开授权页；不能要求再点“打开授权页”。
     `await` / `.then` 续体是否仍有浏览器手势权限不得猜测，必须在实际浏览器验证；没有打开成功就明确提示被拦，不把源码调用 `window.open` 当成成功证据。
 ④ 开窗成功：文案变「已打开授权页，请在浏览器里完成登录…」并开始轮询
 ⑤ 开窗被拦（window.open 返回 null 或 .closed）：文案变
     「浏览器拦截了弹窗」+ 一行小字可点击的授权链接（兜底路径，不是主路径）
 ⑥ 轮询命中 granted：停止轮询 → 刷新账号列表 → 自动选中新账号 → 文案「已登录：<昵称>」
```

## 二、状态机（界面只有这五个态）

| 态 | 触发 | 界面表现 |
|---|---|---|
| `idle` | 初始 | 主按钮「登录 Qoder」可点；若无账号，提交按钮禁用并提示「尚未登录 Qoder」 |
| `starting` | 点了登录，start 请求在途 | 按钮禁用 + 「正在打开授权页…」 |
| `waiting` | 已开窗，领取结果中 | 显示等待态；辅助重开只用同一 URL，不新建会话；不重建其他输入，且本次授权不能被历史成功覆盖 |
| `granted` | 轮询返回 granted | 自动选中新账号；文案「已登录：<昵称>」；按钮恢复可点（可再登一个账号） |
| `failed` | start 失败 / 轮询 expired / cancelled / 窗口被用户关闭 | 一句话原因 + 重试入口（按钮恢复） |

## 三、硬禁止项（违反即返工）

1. **不许让用户点第二次**：授权页必须由第一次点击直接打开；「打开授权页」不得作为主路径按钮。
2. **不许整页重建**：轮询期间只更新账号区容器（`[data-reverse-accounts]`）；禁止再调 `viewRoot.innerHTML = renderAddGroup(...)`。
3. **不许丢输入**：任何一次渲染前后，群名称/地址等输入值与焦点必须保持。
4. **界面不出现「导入」**：导入仅保留 HTTP 接口（供 CLI 与将来使用），UI 不暴露。
5. **界面不出现命令行**：文案里禁止 `node scripts/...`；失败要说人话。
6. **轮询必须可停**：`granted / expired / cancelled / 用户关闭窗口 / 切换平台 / 离开页面` 六种情况下都要清理定时器。
7. **界面名字不带内部术语**：平台显示为 `Qoder`，不许出现「（反代）」。

## 四、轮询细则

- 轮询节奏由平台声明；对端无回调时才使用轮询，不以固定 sleep 代替状态信号。
- 授权期限由服务端明确返回的状态 / 期限判定，前端不另定一份预算并用它伪装“授权超时”。
- 成功、失败、取消、切换平台和离开页面都清理轮询；窗口关闭本身不证明服务端取消授权。
- 状态更新仅改变账号区域，不销毁其他输入；回执必须属于本次操作。

## 五、文案表（照抄，别自己编）

| 场景 | 文案 |
|---|---|
| 等待授权 | 等待授权…（浏览器里完成登录后会自动刷新） |
| 弹窗被拦 | 浏览器拦截了弹窗，点这里打开授权页 |
| 成功 | 已登录：<昵称> |
| 超时 | 授权已超时，请重新登录 |
| 窗口被关 | 授权页已关闭 |
| 无账号时提交 | 尚未登录 Qoder，请先点「登录 Qoder」 |
| start 失败 | 无法发起登录：<上游原因原文> |

## 六、验收断言（必须逐条给出输出）

1. 点一次「登录」→ `POST /reverse/login/start` 恰好 1 次，`window.open` 恰好 1 次
2. 连续 10 次轮询后：群名称输入框的值与 `document.activeElement` 不变
3. 轮询期间页面无整块重建（可用 DOM 变更观察：账号区以外节点不发生替换）
4. 弹窗被拦路径：不出现「打开授权页」主按钮，只有兜底链接
5. 界面文案全文搜索：无「导入」、无 `node scripts/`
6. 提交后群配置为 `auth.apiKeyRef = "account:qoder/<accountId>"`
