# assets —— 第三方资源清单

本目录只放**第三方资源**（图标 / 字体 / 音效等）。自有资源放在各自功能目录里。

## 规则

1. 每个入库文件都必须在下表登记：文件、来源项目、许可证、用途。
2. 许可证不明或不允许再分发的资源**不入库**（可以记录 URI，用时再下）。
3. 文件名不带空格；同一来源的同族图标放同一子目录。
4. **新增资源必须补齐四要素**：文件名 / 来源项目 / 许可证 / 用途（缺一不许入库）；**不得放没有来源的二进制**（来源不明 = 不许再分发 = 不入库）。

## 清单

| 文件 | 来源项目 | 许可证 | 用途 |
|---|---|---|---|
| `icons/.gitkeep` | 本项目 | — | 占位：图标目录先建好，实际图标等真的要用再入库 |

## 说明

- 本轮（M1）没有任何第三方资源入库：反代骨架只做纯函数与元数据，界面在后续里程碑才涉及。
- 需要图标时优先用文字/首字母占位（现有 `ui/js` 的 avatar 规则即如此），避免为了一个图标引入来源与许可负担。
